## 📖 About Exodus Wallet

**Exodus Wallet** is a multi-chain cryptocurrency wallet application designed for users who want a simple and visually organized way to manage their digital assets.

Managing multiple cryptocurrencies can become complicated when users need to track balances, transactions, and different blockchain networks. Exodus provides an easy-to-use interface where users can store, monitor, exchange, and organize supported crypto assets from one application.

The wallet focuses on user-friendly design, self-custody, portfolio management, and convenient access across desktop and mobile platforms.

Exodus allows users to maintain control of their crypto assets while providing tools for tracking balances, viewing transaction history, and managing supported blockchain networks.
